# AI Readiness Report Redesign

A conversion-focused redesign concept for Humblebee's AI Readiness Report,
built with Next.js, React and Tailwind CSS.

## Run locally

Requires Node.js 22 and npm.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

Import this repository into Vercel. The framework preset, build command and
output settings are detected automatically from the Next.js project.

## Prototype behaviour

The application form is intentionally a front-end prototype. It displays a
confirmation state but does not transmit or store submitted information.
